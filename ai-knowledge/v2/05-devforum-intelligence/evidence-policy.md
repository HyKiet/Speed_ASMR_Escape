# DevForum Evidence Policy

Last Updated: 2026-04-24
Source: https://devforum.roblox.com/

## Purpose
Use DevForum for edge cases, bug symptoms, and practical workarounds.
Do not treat forum content as final API authority.

## Evidence Scoring
- D1: Thread with no reproduction and no accepted answer.
- D2: Reproducible thread with community consensus.
- D3: Reproducible plus staff confirmation.

## Mandatory Validation Before Adoption
1. Reproduce issue in Studio.
2. Verify suggested API behavior in official docs.
3. Capture final decision in project playbook.

## Output Requirement For AI Responses
When citing forum-derived insight, include:
- issue summary,
- repro conditions,
- final authoritative API confirmation,
- fallback strategy if behavior changes.
